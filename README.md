## 🛠️ 2. CI/CD Пайплайн и Безопасность
Выполнен деплой приложения с помощью автоматизированного пайплайна.
*   **Безопасность данных:** Файл конфигурации `Kubeconfig` **НЕ хранится** в открытом виде в репозитории. Он замаскирован и передается в рантайм сборщика через защищенную переменную окружения (CI/CD Secret Variable).
*   📸 *Артефакт:* Скриншот успешного выполнения пайплайна и шагов сборки: `/screenshots/cicd-pipeline.png`.

*   📸 *Артефакт:* Скриншоты нагрузки и маштабирования: `/screenshots/задача 5-1.png`, `/screenshots/задача 5-2.png`.

*   📄 *Манифест HPA:* Доступен в файле `/Задача 5 frontend-hpa.yaml`.
